# Kanalstandard-Workshop

`kanalstandard-workshop.html` ist eine eigenständige, interaktive
Workshop-Arbeitsgrundlage. Sie kann ohne Build-Schritt direkt im Browser
geöffnet werden.

Enthalten sind:

- ein zeitlich begrenzter Ablauf für den ersten Bestandskanal-Termin,
- eine lokal speicherbare Entscheidungs- und Beschlussmatrix,
- die erfassten Bestands-, Planungs- und Versorgungs-Layernamen,
- offene Prüfpunkte zu Schreibweisen, Farben, Linientypen und Maßstäben,
- eine druckoptimierte Ausgabe für PDF oder Papier.

Eingaben werden ausschließlich im `localStorage` des jeweiligen Browsers
gespeichert.
