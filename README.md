# Workshop-B-N

## Kanalstandard – Informationsaufnahme

`kanalstandard.html` ist eine eigenständige HTML-Datei (kein Build-Schritt nötig), die die vollständige, quellenbezogene Informationsaufnahme für den geplanten Kanal-Zeichenstandard dokumentiert: Originalkontext, Zielbild, Ablauf für den ersten Termin, Kanalarten, Layerstruktur Bestandskanal (42 BKAN-Layer), Kanalplanung (KANPL), Versorgungsleitungen (22 BVER-Layer), den vollständigen filterbaren Layer-Manager (66 Datensätze), den Linientyp- und Farbenkatalog, bewusste Prüfpunkte/Inkonsistenzen sowie einen wiederverwendbaren Master-Prompt für die nächsten Workshop-Schritte.

Datei einfach im Browser öffnen:

```bash
open kanalstandard.html        # macOS
xdg-open kanalstandard.html    # Linux
```

Die Original-CAD-Bilder (image108.png–image117.png, Linientyp- und Farbauswahl-Screenshots) sind als Platzhalter mit vollständiger Bildunterschrift referenziert (Abschnitt 6, 13, 14) und sollten bei Bedarf in einen `images/`-Ordner gelegt und in den entsprechenden `<div class="thumb">`-Blöcken als `<img>` ergänzt werden.
